# TalentDock – Interactive Job Recruitment Platform

A modern, fully responsive job discovery platform where software engineers, designers, and data professionals can find and apply for jobs. Built as a frontend engineering challenge.

## 🚀 Features
- **Job Discovery Dashboard:** Browse featured and latest jobs with a modern UI.
- **Advanced Search & Filtering:** Filter dynamically by category, salary, experience level, job type, location (remote/onsite), and date posted.
- **Job Details Page:** Dynamically routes to specific job details including qualifications, responsibilities, and compensation.
- **Application System:** Validated application form that saves to LocalStorage and prevents duplicate applications.
- **Saved Jobs:** Bookmark jobs and persist them across browser refreshes.
- **Application History:** Track the status of submitted applications.
- **Fully Responsive:** Custom mobile layout with a hamburger menu and stacked grids.

## 🛠️ Tech Stack
- **React** (with Vite)
- **TypeScript**
- **React Router DOM** (Navigation)
- **Lucide React** (Icons)
- **CSS3** (Custom responsive styling, no external frameworks)
- **Vitest** (Unit Testing for filtering and validation)
